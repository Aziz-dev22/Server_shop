# 🤖 Hetzner Shop Bot

ربات تلگرامی فروش و مدیریت سرور مجازی (VPS) روی Hetzner Cloud + پنل مدیریت تحت وب — کاملاً آماده و بدون نیاز به دانش برنامه‌نویسی.

فقط ۶ فایل دارد:

| فایل | کاربرد |
|---|---|
| `bot.py` | کل منطق ربات تلگرام |
| `panel.py` | پنل مدیریت تحت وب (از همان دیتابیس و منطق `bot.py` استفاده می‌کند) |
| `requirements.txt` | لیست کتابخانه‌های موردنیاز |
| `.env.example` | نمونه فایل تنظیمات |
| `install.sh` | نصب / آپدیت / بکاپ / حذف با یک دستور (هر دو سرویس ربات و پنل را مدیریت می‌کند) |
| `README.md` | همین راهنما |

دیتابیس از نوع **SQLite** است (یک فایل، بدون نیاز به نصب دیتابیس جداگانه).

---

## ✅ چه امکاناتی دارد؟

**برای کاربر:**
- ثبت‌نام خودکار با اولین `/start`
- خرید سرور: انتخاب دیتاسنتر → پلن → سیستم‌عامل → پرداخت از کیف پول → تحویل خودکار IP و پسورد
- **همه قیمت‌ها به دلار ($) و به‌صورت زنده از قیمت واقعی اکانت Hetzner محاسبه می‌شوند** (به‌علاوه درصد سودی که ادمین تعیین کرده)
- مشاهده و مدیریت سرورها (روشن / خاموش / ریبوت / تغییر پسورد / **نصب مجدد سیستم‌عامل (Rebuild)** / حذف)
- مشاهده تاریخچه سفارش‌ها
- شارژ کیف پول به دو روش:
  - 💠 **پرداخت خودکار با ارز دیجیتال** (از طریق OxaPay، بدون نیاز به تایید دستی)
  - 🏦 **واریز دستی** به کارت یا آدرس ولتی که ادمین مشخص کرده (با تایید دستی ادمین)
- پروفایل کاربری
- پشتیبانی (ارسال پیام مستقیم به ادمین)

**برای ادمین (با دستور `/admin` در تلگرام یا از پنل تحت وب):**
- مشاهده کاربران، سفارش‌ها و آمار کلی (تعداد کاربران، سرورها، درآمد)
- **مدیریت چند API Key هتزنر همزمان** — افزودن، مشاهده، فعال‌سازی و حذف هرکدام
- تعریف پلن‌های فروش فقط با انتخاب نوع سرور واقعی Hetzner و تعیین **درصد سود** (قیمت نهایی خودش زنده محاسبه می‌شود) — هر پلن می‌تواند مخصوص یک لوکیشن خاص یا همه لوکیشن‌ها باشد
- **فعال/غیرفعال کردن هر دیتاسنتر Hetzner به‌صورت جداگانه** برای فروش
- پلن‌هایی که هم‌اکنون در آن دیتاسنتر موجودی سخت‌افزاری ندارند به‌صورت خودکار از دید کاربر پنهان می‌شوند
- تنظیم درگاه پرداخت ارز دیجیتال (OxaPay API Key)
- تنظیم آدرس واریز دستی (شماره کارت یا آدرس ولت)
- **دسترسی کامل به همه‌ی سرورهای همه‌ی کاربران** با دکمه‌های روشن/خاموش/ریبوت/پسورد/Rebuild/حذف — حتی سرورهایی که مستقیماً در پنل Hetzner (نه از طریق ربات) ساخته شده‌اند، با «همگام‌سازی» به‌صورت خودکار پیدا و قابل‌مدیریت می‌شوند
- **مدیریت کامل هر کاربر با یک کلیک**: افزایش/کاهش موجودی کیف پول، دیدن و مدیریت سرویس‌هایش، مسدود/رفع مسدودیت
- **ساخت سرور رایگان برای خودش** (بدون کسر از کیف پول) از هر نوع و در هر دیتاسنتری
- تایید یا رد درخواست‌های شارژ دستی
- ارسال پیام همگانی به تمام کاربران
- در هر صفحه از ربات دکمه «🔙 بازگشت» وجود دارد، بدون نیاز به `/start` مجدد

**🌐 پنل مدیریت تحت وب (`panel.py`):**
تمام امکانات بالای بخش ادمین از یک آدرس اینترنتی هم در دسترس است — مناسب کسانی که ترجیح می‌دهند از مرورگر مدیریت کنند. با نام کاربری/رمز عبوری که هنگام نصب تعیین می‌کنید وارد می‌شوید و دقیقاً همان دیتابیس ربات را می‌بینید و مدیریت می‌کنید (هیچ تنظیم تکراری لازم نیست).

## 🚀 نصب / آپدیت / بکاپ / حذف (با یک دستور)

روی سرور اوبونتو (Ubuntu 22.04 یا 24.04) این یک خط را اجرا کنید:

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/Aziz-dev22/server_shop/main/install.sh)
```

یک منو با ۴ گزینه نمایش داده می‌شود:

```
1) نصب                 → نصب کامل ربات از صفر
2) آپدیت                → دریافت آخرین نسخه کد از گیت‌هاب (تنظیمات و دیتابیس حفظ می‌شود)
3) بکاپ کامل             → گرفتن یک فایل فشرده از کل ربات (تنظیمات + دیتابیس)
4) حذف کامل             → توقف و پاک‌سازی کامل ربات از روی سرور (با تاییدیه و امکان بکاپ قبل از حذف)
```

عدد مربوطه را وارد کرده و Enter بزنید.

هنگام **نصب**، این موارد پرسیده می‌شود:
1. **توکن ربات تلگرام** — از [@BotFather](https://t.me/BotFather) با دستور `/newbot`
2. **شناسه عددی تلگرام ادمین** — از [@userinfobot](https://t.me/userinfobot)
3. **نام کاربری و رمز عبور دلخواه برای ورود به پنل تحت وب**

بقیه تنظیمات (اتصال Hetzner، درگاه ارزی، آدرس واریز، پلن‌ها، لوکیشن‌ها) از **داخل خود ربات با `/admin`** یا از **پنل تحت وب** انجام می‌شود.

## ⚙️ راه‌اندازی اولیه بعد از نصب (داخل تلگرام)

1. به ربات خودتان پیام `/start` بدهید.
2. دستور `/admin` را بزنید تا پنل مدیریت باز شود.
3. روی **«🔑 مدیریت API های Hetzner»** بزنید → **«➕ افزودن API جدید»** → یک نام دلخواه و سپس API Token پروژه Hetzner Cloud خود را وارد کنید.
   - توکن را از پنل Hetzner: `Project > Security > API Tokens` با دسترسی **Read & Write** بسازید.
   - می‌توانید چند اکانت/پروژه هتزنر اضافه کنید و هر زمان بین آن‌ها جابه‌جا شوید.
4. روی **«🧩 مدیریت پلن‌ها»** → **«➕ افزودن پلن جدید»** بزنید، یکی از سرورهای واقعی Hetzner را انتخاب کنید، یک اسم دلخواه بگذارید و **درصد سود** را وارد کنید (مثلاً 20 برای ۲۰٪ سود روی قیمت پایه هتزنر). دیگر نیازی به وارد کردن قیمت دستی نیست.
5. اگر می‌خواهید پرداخت خودکار ارز دیجیتال فعال باشد: روی **«💠 درگاه ارز دیجیتال (OxaPay)»** بزنید و Merchant API Key حساب OxaPay خودتان را وارد کنید (بدون نیاز به دامنه یا وب‌هوک، ربات خودش وضعیت پرداخت را چک می‌کند).
6. روی **«🏦 آدرس واریز دستی»** بزنید و شماره کارت یا آدرس ولت ارز دیجیتالی که برای واریز دستی کاربران استفاده می‌شود را وارد کنید.
7. از همین حالا کاربران می‌توانند از منوی **«🛒 خرید سرور»** خرید کنند.

## 🔧 دستورات مدیریت سرویس

```bash
systemctl status hetzner-shop-bot       # وضعیت ربات
journalctl -u hetzner-shop-bot -f       # مشاهده لاگ زنده ربات
systemctl restart hetzner-shop-bot      # ری‌استارت ربات

systemctl status hetzner-shop-panel     # وضعیت پنل تحت وب
journalctl -u hetzner-shop-panel -f     # مشاهده لاگ زنده پنل
systemctl restart hetzner-shop-panel    # ری‌استارت پنل
```

پنل تحت وب پیش‌فرض روی پورت `8088` بالا می‌آید: `http://IP-SERVER:8088`
مطمئن شوید این پورت در فایروال سرور باز است، مثلاً:
```bash
ufw allow 8088
```
برای امنیت بیشتر توصیه می‌شود پنل را پشت یک دامنه و HTTPS (با nginx + certbot) قرار دهید.

## 💡 نکات مهم

- قیمت‌های هتزنر معمولاً به **یورو** برگردانده می‌شوند؛ ربات به‌صورت خودکار با نرخ لحظه‌ای یورو/دلار (که هر ۶ ساعت بروزرسانی می‌شود) آن را به دلار تبدیل کرده و سپس درصد سود ادمین را روی آن اعمال می‌کند.
- درگاه OxaPay نیازی به دامنه یا وب‌هوک عمومی ندارد؛ ربات هر ۴۵ ثانیه وضعیت فاکتورهای پرداخت‌نشده را از OxaPay استعلام می‌گیرد و بعد از تایید، خودش کیف پول را شارژ می‌کند.
- اگر هنوز درگاه ارز دیجیتال را تنظیم نکرده باشید، فقط گزینه «واریز دستی» به کاربران نمایش داده می‌شود.
- فایل دیتابیس `shop.db` داخل پوشه `/opt/hetzner-shop-bot` ساخته می‌شود؛ گزینه «بکاپ کامل» در نصب‌کننده این فایل را همراه تنظیمات، به‌صورت خودکار در `/root/hetzner-shop-bot-backups` ذخیره می‌کند.
- برای بروزرسانی ربات در آینده، فقط دستور نصب یک‌خطی را دوباره اجرا کرده و گزینه «۲) آپدیت» را انتخاب کنید.
